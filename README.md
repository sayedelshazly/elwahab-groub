# El-Wahab Group Landing Page

A responsive, cinematic automotive landing page built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Keep the `assets` folder beside the HTML/CSS/JS files.

## Included
- Responsive desktop and mobile layouts
- Mobile navigation menu
- Scrollable vehicle gallery with previous/next controls and progress
- Motion-reduction preference support
- Contact details and direct phone, email, WhatsApp, and map links
- Optimized/enhanced image crops made from the two images supplied in the conversation

## Content notes
The company descriptions and contact information are based on publicly available El-Wahab Group website content. Please confirm details before publishing. Gallery labels are descriptive captions for the provided vehicle collage; replace any mismatched crop or caption with an approved original photo where needed.

## External dependencies
Google Fonts (Barlow Condensed and Open Sans) are loaded online. The site remains readable using system fallbacks if they are unavailable.
